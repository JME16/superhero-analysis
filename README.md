Superhero Operations Analysis

## Project Overview

This project uses PostgreSQL to analyze operational decisions made by a fictional superhero organization.

The central analytical question is:

**How can the League deploy enough capability to stop a villain while avoiding unnecessary collateral damage?**

The database combines mission history, hero deployments, villain threats, event types, damage estimates, operating costs, and mission outcomes to evaluate the tradeoff between operational effectiveness and damage control.
