Superhero Operations Analysis

## Project Overview

This project uses PostgreSQL to analyze operational decisions made by a fictional superhero organization.

The central analytical question is:

**How can the League deploy enough capability to stop a villain while avoiding unnecessary collateral damage?**

The database combines mission history, hero deployments, villain threats, event types, damage estimates, operating costs, and mission outcomes to evaluate the tradeoff between operational effectiveness and damage control.

## Dataset Provenance and AI Collaboration

This portfolio uses a **fictional, AI-generated synthetic dataset**, not operational records from a real organization. AI supported dataset creation and analytical collaboration; SQL-based checks, interpretation of results, and the decision to investigate anomalies are documented as part of the analyst's work. Findings are illustrative, not real-world performance claims.

Repeated operating-cost values across comparable missions suggest a standardized cost model in the synthetic data. Identical spending does not imply identical outcomes or equal operational difficulty. Therefore, team cost rankings and apparent efficiency differences are interpreted cautiously, with mission mix and missing planning context explicitly acknowledged. See [`results/key_findings.md`](results/key_findings.md) for detailed notes and limitations.
